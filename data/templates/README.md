# Data Templates

Copy these templates when building your scraper output. Save completed files to `data/` (one level up).

| Template | Save as | Required? |
|----------|---------|-----------|
| `compare_data_new.template.csv` | `compare_data_new.csv` | **Yes** — canonical route prices |
| `merged_flight_data.template.csv` | `merged_flight_data.csv` | **Yes** — airport coords + cities |
| `compare_data.template.json` | `compare_data.json` | Auto-generated by script |
| `trend_data.template.json` | `trend_data.json` | Auto-generated (or scrape monthly fares) |
| `class_layover.template.json` | `class_layover_data.json` | Auto-generated (or scrape class prices) |
| `nearby_airports.template.json` | `nearby_airports.json` | Auto-generated (or scrape alternatives) |
| `heatmap_data.template.json` | `heatmap_data.json` | Auto-generated from CSV |

After updating the two CSV files, run:

```bash
python scripts/generate_data.py
```

See [docs/DATA.md](../../docs/DATA.md) for full field reference and [docs/SCRAPING.md](../../docs/SCRAPING.md) for what to scrape and from where.

After pushing updated data to GitHub, Render auto-redeploys and reloads the cache. See [docs/DEPLOYMENT.md](../../docs/DEPLOYMENT.md).
